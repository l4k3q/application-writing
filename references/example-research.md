# PS/SOP 样例调研

用于信息搜集阶段。搜索与目标学校、项目层级、学科和文书类型相关的公开写作指南及完整或带批注的文书样例。先看目标项目官方题目，再找该校招生办公室、写作中心或院系的材料；若目标校没有公开样例，可参考相近专业的其他大学官方样例，并注明迁移边界。非官方个人分享可作补充，不能据此声称该写法得到招生方认可。

## 搜索与筛选

- 试用 `SOP example + 学校名 + 专业`、`statement of purpose sample site:学校域名`、`personal statement example + 学校名`、`writing guide + 学校名 + graduate admissions` 等检索式；检查原页面、发布机构、文书类型、学位层级及日期。
- 优先选内容可读、与本次任务相关、能解释写作选择的样例。学校公开或批注的样例仍只证明该篇写法可供分析，不代表当前招生项目保证接受同样结构。
- 区分真正的申请文书样例与纯写作指南。指南可以帮助分析，但不要伪装成某位申请人的“优秀文书”。找不到合适样例时报告检索范围与缺口，不编造样例。

## `doc/` 文件

每篇选中的文书样例建立一个独立 Markdown 文件，放在该申请材料目录的 `doc/`，以文书类型、来源学校和主题命名，避免重名。每个文件包含：

1. 标题、文书类型、学科或项目、学位层级、来源机构及页面发布日期（若有）；
2. 原文直接链接、访问日期，以及来源是官方样例、官方批注样例还是非官方分享；
3. 用自己的话概述开头、主线、段落推进、具体证据与结尾如何起作用；
4. 分析它如何用行动与细节呈现 passion、能力或 goal，以及在何处直接解释意义；
5. 写明本次申请可借鉴的做法和不能照搬之处，尤其是机构题目、作者经历与专业差异。

文件保存链接与分析，不转载整篇原文。确需引用时只使用必要的短片段并注明出处。不要复制样例作者的故事、句子或专属项目匹配表述。

## 使用样例

在 brainstorm 中用样例启发结构与叙事选择，同时以申请人自己的事实生成候选主线。PS 可借鉴有动作、选择与变化的故事推进；SOP 可借鉴明确的学术问题、方法、准备与项目契合。具体题目和 `requirements.md` 的硬性限制优先于样例结构。
