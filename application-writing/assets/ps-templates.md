# PS：8 个原创写作模板

这些是根据大学公开指南归纳的**结构模板**，不是录取文书原文，也不是固定格式。先核对目标项目的题目：有的学校把个人经历放在 personal history statement，有的把研究动机也称为 personal statement。方括号只提示应寻找的真实材料；缺少材料时追问，不能补造经历或感受。

模板只用于选结构；实际成稿按 [PS 版式与双语交付规则](../references/ps.md)处理，审阅稿在完整目标语言正文下方附完整中文参考译文。

## 1. 一个选择，随后的一串选择

**适用**：有一项具体决定，其影响延续到后来的学习或行动。

1. 从[当时必须做的选择]和[真实限制]进入，不用宏大的童年宣言。
2. 写自己做了什么、为何这样取舍，以及最初结果。
3. 展示随后一次不同场景中的选择，说明兴趣或判断如何变得更清楚。
4. 以现在想继续追问的问题和申请机会收束。

**核查**：两次选择之间要有可解释的联系，不能为了故事性虚构转折。[参考：Berkeley Graduate Division](https://grad.berkeley.edu/admissions/application-process/writing-your-statements/)。

## 2. 从一次失败看到问题

**适用**：确有失败、意外结果或方法失效，并采取了后续行动。

1. 简述[意外结果]及原先预期。
2. 写排查、修改或求助时的具体行动，标明自己的贡献。
3. 说明哪些假设被修正，哪些问题仍未解决。
4. 连接下一阶段的学习或研究动机。

**核查**：不把普通挫折戏剧化；重点放在选择与变化。[参考：MIT NSE Communication Lab](https://mitcommlab.mit.edu/nse/commkit/graduate-school-personal-statement/)。

## 3. 一项长期关注如何成形

**适用**：没有单一“顿悟时刻”，但多段经历围绕同一问题。

1. 先提出反复出现的[问题或关注点]。
2. 用两段不同经历说明自己先后如何接近它，行动要具体。
3. 解释后来理解与最初理解的差异。
4. 指向下一步想探索的领域或项目。

**核查**：共同主题须由经历支持，不能只靠抽象的“热爱”。[参考：Stanford Humanities and Sciences](https://humsci.stanford.edu/prospective-students/guide-getting-grad-school/writing-your-personal-statements)。

## 4. 从个人背景到具体贡献

**适用**：背景、责任或社区经历确实影响了学习路径与行动。

1. 只交代理解后续选择所必需的背景。
2. 聚焦自己在[具体情境]中采取的行动及面对的约束。
3. 说明它怎样改变问题意识、合作方式或所做贡献。
4. 联系未来能带入目标项目的视角。

**核查**：不把身份本身当成成就，不要求披露敏感经历。[参考：Berkeley Personal History Statement 指南](https://grad.berkeley.edu/admissions/application-process/writing-your-statements/)。

## 5. 跨领域转向

**适用**：研究或专业方向改变，且有可核实的过渡经历。

1. 从旧领域中遇到的具体局限或新问题开始。
2. 写如何接触新领域：课程、项目、作品或合作。
3. 解释旧能力怎样迁移，同时承认仍需补足的训练。
4. 说明申请机会如何支持这个转向。

**核查**：不用“突然发现真正的自己”代替中间证据。[参考：Berkeley Career Engagement](https://www.career.berkeley.edu/get-into-grad-school/graduate-school/statement-of-purpose/)。

## 6. 一段合作改变了做事方式

**适用**：合作、服务或教学中有可描述的互动和改变。

1. 交代共同任务、不同需求或分歧。
2. 写自己如何倾听、协调、修改方案，并展示他人的真实作用。
3. 说明结果及自己学会了怎样工作。
4. 回到未来在学习共同体中的贡献。

**核查**：别把团队结果全部归于自己，也别把他人当背景板。[参考：Berkeley Graduate Division](https://grad.berkeley.edu/admissions/application-process/writing-your-statements/)。

## 7. 责任与学习并行

**适用**：工作、家庭或其他责任真实影响了求学路径，申请人愿意披露。

1. 简洁交代责任及其对时间、机会或选择的实际影响。
2. 写采取的具体安排、争取的资源和完成的工作。
3. 说明这段经历所形成的能力、兴趣或问题意识。
4. 以现在的准备与下一步目标结束。

**核查**：不把困难写成必须克服一切的英雄故事。[参考：Berkeley Personal History Statement 指南](https://grad.berkeley.edu/admissions/application-process/writing-your-statements/)。

## 8. 仍在探索的方向

**适用**：申请人尚无固定职业终点，但有真实的探索行动。

1. 提出已经在行动中反复出现的[具体问题]。
2. 用一段经历说明已尝试的办法及其局限。
3. 写目前在两个相邻方向间尚未解决的判断，而非编造确定志向。
4. 说明目标机会提供何种验证路径，以及近期想完成什么。

**核查**：可以诚实表达探索，但不能把空泛犹豫写成研究计划。[参考：MIT Graduate School Application Essays](https://capd.mit.edu/resources/graduate-school-application-essays/)。
