# CV / Resume：8 个原创版式模板

先确认项目要完整 academic CV、限定页数 CV，还是求职式 resume。以下每个模板给出栏目顺序与条目写法；只保留有真实内容的栏目。日期、职位、作者顺序、论文状态、量化结果须可核验。栏目顺序体现申请目标，并非所有申请都需要八种版式。

模板只用于选栏目与结构；实际成稿按 [CV 版式与双语交付规则](../references/cv.md)处理，审阅稿在完整目标语言 CV 下方附逐条对应的中文参考译文。

## 1. 本科生申请首次研究机会

**顺序**：姓名与联系方式 → Education → Relevant Coursework（仅有明确相关课程时）→ Course / Independent Projects → Technical Skills → Awards / Service。

**条目**：`[课程/项目名]｜[时间]`；`为解决[问题]，使用[方法]完成[个人动作]；产出[可展示结果或链接]。`

**重点**：没有正式研究经历也可展示严谨项目，不能把课程项目写成实验室研究。[参考：MIT 本科生简历样例](https://capd.mit.edu/resources/sample-resumes/)。

## 2. 研究密集型硕博申请

**顺序**：Education → Research Interests（可选，需具体）→ Research Experience → Publications / Preprints → Presentations → Teaching → Honors → Skills。

**条目**：`[角色]，[课题组/机构]，[时间]`；两条分别交代研究问题与个人方法、结果或产出。

**重点**：出版物状态分开列，不把团队论文写成独立作者成果。[参考：Harvard GSAS CV Guide](https://careerservices.fas.harvard.edu/resources/gsas-cv-cover-letter-guide-2/)。

## 3. 暑研岗位匹配版

**顺序**：Education → Selected Research / Projects → Relevant Methods → Publications / Posters（如有）→ Other Experience。

**条目**：每个项目先写与岗位问题直接相关的个人动作，再写方法和证据；技能只列能解释项目经历的工具。

**重点**：按目标实验室或项目调整选材，保留其他经历的真实时间线。[参考：Berkeley Sample Resumes](https://www.career.berkeley.edu/prepare-for-success/resumes/sample-resumes/)。

## 4. 计算 / 工程作品版

**顺序**：Education → Selected Technical Projects → Research / Work Experience → Publications → Skills → Awards。

**条目**：`[项目]｜[链接]｜[时间]`；`实现[可核验模块]，在[条件/数据集]下用[方法]评估[结果]。`

**重点**：区分独立设计、改造开源实现和参与团队项目，性能指标须有实验记录。[参考：MIT 跨学科简历样例](https://capd.mit.edu/resources/sample-resumes/)。

## 5. 从行业回到学术

**顺序**：Education → Research / Applied Inquiry → Professional Experience → Publications / Reports → Methods → Service。

**条目**：选能显示问题定义、试验、分析和判断的工作经历，不只罗列业务职责。

**重点**：若无可公开数据，用具体方法和交付物说明价值；避免泄露雇主保密信息。[参考：Harvard PhD Resume / CV Guide](https://careerservices.fas.harvard.edu/resources/resumes-cover-letters-for-phd-students/)。

## 6. 教学或指导贡献突出

**顺序**：Education → Teaching / Mentoring → Research → Publications → Curriculum / Outreach → Awards → Skills。

**条目**：说明授课或指导对象、实际职责、所设计的材料和可核验结果；区分独立授课与助教。

**重点**：面向重视教学的项目才前置此栏，研究成果仍保持可查。[参考：Berkeley Academic CV Overview](https://www.career.berkeley.edu/grad-students-postdocs/academic-job-search/the-cv-part-1-overview/)。

## 7. 跨学科申请的双主线版

**顺序**：Education → Research Projects（按目标问题排序）→ Complementary Experience → Publications / Outputs → Methods（按领域分组）→ Awards。

**条目**：给每项经历一个准确的领域标签，用动作与结果说明两类训练如何服务于申请目标。

**重点**：不为对齐关键词重命名实际专业、角色或方法。[参考：Harvard GSAS CV Guide](https://careerservices.fas.harvard.edu/resources/gsas-cv-cover-letter-guide-2/)。

## 8. 有限篇幅的精选版

**顺序**：Education → Most Relevant Experience → Selected Projects / Outputs → Skills；若要求一页，优先删减低相关条目，不缩小到难以阅读。

**条目**：每段经历保留最能证明目标岗位要求的 1–3 条动作与结果。

**重点**：这是面向有限页数的 resume / 简版 CV；若项目要求完整 academic CV，应改用完整记录。[参考：Harvard Resume 与 CV 区分](https://careerservices.fas.harvard.edu/blog/2023/08/28/the-resume-vs-curriculum-vitae-cv/)。
