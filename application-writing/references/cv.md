# CV：申请履历

先确认项目要求的是学术 CV、专业 CV 还是限定页数的 resume，并按机构指定格式组织。CV 的目标是让评审快速核对经历与成果，不承担 PS 或 SOP 的叙事任务。

## 成稿版式

- 姓名与有效联系方式置顶；相关经历按栏目分组，栏目标题、日期格式、地点、角色和条目缩进保持一致。日期与机构、职位的关系应一眼可读；没有内容的栏目不留空，标题和空白只服务于快速查阅。
- 审阅稿先给完整目标语言 CV，再以分隔线和“中文参考译文”给出同样栏目顺序的完整中文版本。逐条对应翻译，不省略成果或更改论文状态；姓名、机构、论文题目和专业术语按准确性保留原文或附中文说明。上传版只保留机构要求的语言与格式。

## 结构判断

- 按相关性选择教育、研究、工作、项目、论文、报告、奖项、技能、教学和服务等栏目；没有内容的栏目不占位。
- 核对机构名、学位、日期、角色、导师、作者顺序、论文状态和成果链接。正在进行、已投稿、已接收、已发表分别表述。
- 条目优先写个人动作、对象、方法和可核验结果；团队成果保留个人贡献边界。
- 对目标项目调整栏目顺序和重点，不靠增加未经证实的关键词匹配要求。

## 交付检查

- 各条目时间线可读，格式一致；缩写在必要处解释。
- 量化结果有来源；没有可靠数字时用具体的定性结果。
- 与 PS、SOP、RL 中的姓名、日期、项目名称和成果状态一致。
