# 选题与联系分析

用于新写或大幅重写文书的起草前阶段。目标是发现申请人材料中值得讲的联系，并用外部项目资料检验其相关性。brainstorm 可以提出新角度，不能凭空补出申请人的经历或感受。

## 产生候选主线

从以下维度交叉寻找 2–3 个彼此不同的角度，不必逐项遍历：

- 申请人在哪个项目、课程或工作中做过具体选择？当时有什么限制，为什么那样做？
- 哪个结果、失败、权衡或未解问题改变了下一步想法？现有材料只记录“做了什么”时，将可能的认识写为待确认问题。
- 目标机构有哪些经过核对的研究方向、课程、方法或培养安排，可以帮助继续探索这个问题？这项联系是否比泛泛说“声誉好”更具体？
- 申请人能贡献什么已有能力，同时希望通过该机会学习什么？不要让全文只呈现索取或只列技能。

对每个候选角度简要呈现：**一句核心判断 → 支撑事实 → 事实之间的因果或转折 → 目标项目的具体接点 → 待确认问题**。根据材料强度指出哪个角度最值得展开；申请人可以选择、调整或否定。不得把候选解释直接写成申请人的确定感受。

## 申请人尚无明确方向时

- 先把本次题目、官方写作建议与相关样例转成申请人看得懂的判断：这篇需要回答哪些问题，现有材料中哪些细节能证明观点，哪些只是履历重复或没有依据的口号。可用同一段真实经历示范两种可能写法的差异，不让申请人先定义“好文书”。样例仅供分析，不代表该校保证认可某种结构。
- 用已有证据提出 2–3 条可行主线，简短比较**事实支撑、与题目的关系、项目契合、与其他申请材料的区分度、尚待确认的主观判断**。给出首选及原因，同时允许申请人纠正、合并或否定；不要只给菜单让申请人自行承担选题。
- 若申请人不知道未来要做什么，从已有行动和目标项目资源推导几个合理的近期探索方向，区分“已确定目标”“有证据支持的兴趣”和“尚待检验的可能性”。推荐一个能被现有经历支撑的下一步问题或计划，使用探索性的准确表达，不编造终身志向、坚定情感或已确定的职业承诺。
- 信息足以支持真实叙述时，按推荐方向继续到结构和暂定草稿，让申请人评价具体表达。若个人动机、关键选择或结果缺失到无法真实连接故事，先给可用结构和已证实段落，再集中问最少的关键问题；不要用虚构情节填空。

## 提问要能挖出材料

优先问会改变文书主线的问题，集中在一轮，避免让申请人重填完整履历。例如：“哪个实验结果让你开始怀疑原先的评估方式？”“你为何选这个方法，而没有选更简单的方案？”“你想在暑研中验证什么，现有项目为什么还做不到？”先说明现有材料提示了什么，再问一个具体动作、场景或判断；可给出两种解释请申请人纠正。接受简短、片段式回答和“不知道”，再据此帮用户整理，而不是要求用户自己先写好故事、判断文书质量或提出职业规划。

## 不同文书的 brainstorm 重点

- **PS**：个人选择、转折、长期关注的问题；避免制造戏剧化起点。
- **SOP**：研究或专业问题如何从既有工作中产生，目标项目怎样支持下一步。
- **暑研申请信**：一条最相关的技术经历、由它引出的研究问题、能带来的能力与希望学习的能力。
- **CV**：哪些经历最能证明当前申请方向，如何通过排序与条目重点体现关联；不要求散文式故事。
- **RL**：向推荐人收集可亲自证实的具体事例与比较依据；申请人的猜测只能作为供推荐人核对的线索。

## 从角度到结构

选定主线后，先写一行联系链：**事实与行动 → 遇到的问题或形成的判断 → 下一步目标 → 目标机构的具体接点**。若中间只能靠“我很感兴趣”“该校很优秀”连接，就继续研究或追问。把这条链分配到段落，而不是把原材料按时间顺序翻译。
