# SOP：目的陈述

以机构题目为准。SOP 通常需要说明学术或专业方向、已有准备、下一步计划和项目契合。若题目没有指定结构且篇幅允许，可采用下面的标准分段写法；它是规划基线，不强迫所有项目使用同样段数。若题目要求个人经历或价值观，应相应调整，不强行与 PS 分开。

SOP 更偏学术或专业论证：从具体问题、方法选择、研究或项目经历中展示准备，再直接解释研究兴趣、目标与项目资源如何相接。用事实展示能力，但无需把每段写成个人故事；不要只列术语、经历和导师名字。

## 成稿版式

- 按题目决定是否写标题、姓名或项目名称；无规定时使用简洁标题、分明的段落和一致的间距。下方六部分用于规划内容，不意味着必须在成稿中印出六个英文栏目名；仅当题目分项或小标题确有助于阅读时使用。
- 审阅稿在完整目标语言 SOP 之后放分隔线与“中文参考译文”，保持相同段落或小标题层次。上传版只保留机构要求的语言与格式。

## 标准分段写法

1. **总起**：提出申请方向、核心问题和申请目的；职业目标可以在这里点明，也可以留到第五部分展开。
2. **Education Background**：选与目标相关的课程、训练和学术基础，解释它们怎样支撑下一步，而非罗列成绩单。
3. **Professional / Research Experience**：用真实的研究、工作或项目经历展示方法、个人贡献、结果与尚未解决的问题。没有正式科研或工作经历时，以相关项目替代，不改写身份。
4. **Why this school**：说明为何选择该校或项目，将申请人的问题与经核对的培养方向、课程或研究领域连接。
5. **展开项目帮助与资源**：接续第四部分，具体说明哪些课程、导师工作、实验室、实践机会或其他资源能帮助自己完成什么下一步；可以在这里连接职业目标。区分项目已经提供的资源、可能的导师匹配和申请人的计划，不暗示已获得机会。
6. **收尾**：简短回到准备、目标与贡献，结束全文；不重复前几段的清单。

段落之间要有因果和递进：已有准备引出尚待解决的问题，该问题解释学校契合，而具体资源说明如何推进目标。字数紧时可合并相邻部分；机构题目或用户指定结构始终优先。

## 结构判断

- 明确一个可理解的目标问题或方向，避免只写宽泛的“热爱领域”。
- 从已有课程、研究、工作或项目中选证据，说明申请人做过什么、学到了什么、仍想解决什么。
- 将下一步目标与机构的课程、研究方向、培养方式或导师联系起来。核对官方资料与当前招生情况；不要仅罗列名称、夸赞声誉或暗示导师已同意接收。
- 给出合理的近期学习或研究计划，以及目标项目为何适合该计划；避免承诺无法保证的成果。
- 若职业终点尚未确定，用已有工作引出的具体问题和可执行的近期探索计划说明方向；区分正在考虑的研究路径与已经作出的个人决定，不替申请人宣称确定的长期职业目标。

## 与其他材料分工

- 与 CV 对齐事实，但解释经历如何形成能力与问题意识。
- 与 PS 可共享事实，但减少相同故事的重复；若机构只收一篇综合陈述，就在一篇内兼顾个人动机与具体计划。
