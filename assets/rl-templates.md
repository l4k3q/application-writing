# RL：8 个供推荐人审核的证据结构模板

仅在申请机构允许草拟或提供要点时使用。最终评价、措辞、署名和提交由推荐人决定；若机构禁止申请人代拟，把下列结构转为事实简报。`[亲见事实]` 必须来自推荐人直接观察，`[背景材料]` 不得改写成亲见。没有比较依据时删除比较评价。以下不是可冒用推荐人身份的成信。

模板只用于组织推荐人可核对的证据；允许准备信件草稿时，按 [RL 版式与双语交付规则](../references/rl.md)处理，审阅稿在完整目标语言版本下方附完整中文参考译文。

## 1. 课程教师：学术潜力

**适用**：教师亲自评阅过作业、论文或课堂工作。

1. 关系与观察范围：课程、时间、接触频率。
2. 一个具有难度的任务；学生做出的具体判断；教师所见的作品或表现。
3. 学生如何回应反馈，第二次作品有何变化。
4. 基于这些观察评价其在目标项目中的学习潜力。

**证据交接**：课程作品、批注、评分标准；比较评价由教师自行决定。[参考：Harvard 研究生申请建议](https://careerservices.fas.harvard.edu/resources/applying-to-graduate-school/)。

## 2. 研究导师：独立性

**适用**：导师直接指导过问题定义、实验或分析。

**结构**：认识情境 → 学生负责的研究问题 → 一次自主决策及导师看到的依据 → 遇到意外结果时如何处理 → 对研究潜力的评价。区分导师建议与学生独立提出的内容。

**证据交接**：实验记录、代码、报告、组会反馈。[参考：Harvard Undergraduate Science Education](https://scienceeducation.fas.harvard.edu/recommendation-letters)。

## 3. 研究导师：合作与可靠性

**适用**：成果主要来自团队，但导师能观察协作。

**结构**：团队任务与学生角色 → 一次交接、协调或复核的具体情境 → 他人工作因此发生的可观察变化 → 在后续任务中的稳定表现 → 与目标研究环境的关联。

**证据交接**：分工记录、会议纪要、经导师核对的产出；不将团队结果全归于学生。[参考：Harvard 研究生申请建议](https://careerservices.fas.harvard.edu/resources/applying-to-graduate-school/)。

## 4. 工作主管：专业判断

**适用**：申请人在工作中做过主管亲见的权衡。

**结构**：上下级关系和项目范围 → 有约束的任务 → 学生/员工提出的方案及执行 → 可公开的结果 → 这种判断力为何支持目标学习或研究。

**证据交接**：获准公开的工作产出；不泄露客户、数据或保密决策。[参考：Harvard GSAS 推荐信说明](https://gsas.harvard.edu/apply/applying-degree-programs/letters-recommendation)。

## 5. 写作或项目导师：反馈后的成长

**适用**：推荐人看过同一工作多个版本。

**结构**：初稿/初版的具体不足 → 推荐人给出的反馈 → 申请人如何重新分析或验证 → 后续版本出现的实质改变 → 对可培养性与坚持程度的评价。

**证据交接**：版本差异、批注、最终作品；不凭空制造“逆袭”。[参考：Harvard Undergraduate Science Education](https://scienceeducation.fas.harvard.edu/recommendation-letters)。

## 6. 教学主管：讲解与支持他人

**适用**：推荐人观察过助教、辅导或教学设计。

**结构**：职责与对象 → 一次学生理解受阻的情境 → 申请人如何调整解释或材料 → 推荐人观察到的效果 → 对沟通与责任感的评价。

**证据交接**：教学材料、课堂观察或反馈；不要虚构学生评价。[参考：Harvard 研究生申请建议](https://careerservices.fas.harvard.edu/resources/applying-to-graduate-school/)。

## 7. 跨学科导师：迁移能力

**适用**：推荐人在转向新领域时直接指导申请人。

**结构**：原有背景与新任务的距离 → 新领域中必须学会的知识/方法 → 可见的学习和应用过程 → 仍需训练的部分 → 对跨领域研究准备的审慎评价。

**证据交接**：阅读、项目产出、讨论记录；不把学习速度量化为无依据的排名。[参考：Harvard 推荐信建议](https://careerservices.fas.harvard.edu/resources/applying-to-graduate-school/)。

## 8. 多封推荐信的互补版

**适用**：项目要求多位推荐人，避免三封信重复同一经历。

**结构**：先为每位推荐人列出其亲见范围；本封只选择独有的一个或两个事例 → 描述行为和评价依据 → 说明与目标项目相关的能力。申请人可以提供材料清单，不能规定推荐人必须给出何种赞誉。

**证据交接**：逐人核对可亲证实内容，重复事实可保留但不要复制措辞。[参考：Harvard 研究生申请建议](https://careerservices.fas.harvard.edu/resources/applying-to-graduate-school/)。
